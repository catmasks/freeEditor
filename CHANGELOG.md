# Changelog

> All notable version updates are recorded in this file.

## [1.0.0] - 2026-08-18

### New Features

- Added the `Format Painter`, `Undo`, `Redo`, `Clear Formatting`, `Table` plugins.
- Added the `Import Word`, `Export Word` plugins.
- Added the `Export PDF` plugin.
- Added the `Markdown` plugin.

### Fixes

- Fixed multiple known issues.

## [0.0.5] - 2026-08-01

### Added

- Added `Code Block` plugin.
- Added `Divider` plugin.
- Added `Alignment`, `Attachment`, `Underline`, `Strike`, `Superscript`, and `Subscript` text styling plugins.
- Added `Bullet List`, `Ordered List`, and `Task List` plugins.
- Added `Indent`, `Outdent`, `Line Break`, and `Line Height` plugins.
- Added `Blockquote` and `Inline Code` plugins.
- Added `Disabled` and `Read-only` modes.

### Fixed

- Fixed multiple known bugs.

## [0.0.4] - 2026-07-08

### Added

- Added internationalization (i18n) support.

## [0.0.3] - 2026-07-07

### Added

- Completed basic functionality.
